# 🚚 Delivery Logistics Prediction

A Machine Learning project that predicts whether a delivery will be **Delivered** or **Delayed** using logistics and shipment-related data.

## 🧠 Models Used

* Logistic Regression
* Decision Tree
* Random Forest
* XGBoost
* KNN
* SVM

## 📊 Evaluation

Models were evaluated using:

* Accuracy
* Precision
* Recall
* F1 Score
* ROC-AUC

**XGBoost** achieved:

* Accuracy: **90.42%**
* ROC-AUC: **0.9692**

## 🛠️ Technologies

Python • Pandas • NumPy • Matplotlib • Scikit-learn • XGBoost • Jupyter Notebook

```bash
pip install pandas numpy matplotlib scikit-learn xgboost jupyter
```
